# Hilfe & Support

Bei Fragen zu einem Projekt schau zuerst in dessen README, Dokumentation und bestehende Issues.

| Anliegen | Anlaufstelle |
| --- | --- |
| Technischer Fehler | Bug-Report im betroffenen Repository |
| Verbesserungsidee | Feature-Request im betroffenen Repository |
| Technische Rückfrage | [app@willigis-online.de](mailto:app@willigis-online.de) |
| Sicherheitslücke | [SECURITY.md](SECURITY.md) |
| Schulische oder persönliche Angelegenheit | [Kontakt zur Schule](https://www.willigis-online.de/kontakt/) |

Öffentliche Issues sind nicht für persönliche Anliegen, schülerbezogene Daten oder vertrauliche Informationen geeignet. Ein fester Supportzeitraum oder garantierte Antwortzeiten werden nicht zugesagt.
