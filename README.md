# .github · Bischöfliche Willigis-Schulen Mainz

Zentrales Repository für das öffentliche GitHub-Organisationsprofil und gemeinsame Projektvorlagen.

## Aufbau

| Pfad | Funktion |
| --- | --- |
| `profile/README.md` | Öffentliches Organisationsprofil |
| `profile/assets/` | Optional: lokal gespeicherte Profilbilder |
| `.github/ISSUE_TEMPLATE/` | Formulare für Fehler und Verbesserungsvorschläge |
| `.github/PULL_REQUEST_TEMPLATE.md` | Vorlage für Pull Requests |
| `CONTRIBUTING.md` | Hinweise zur Mitarbeit |
| `CODE_OF_CONDUCT.md` | Regeln der Zusammenarbeit |
| `SECURITY.md` | Vertrauliche Meldung von Sicherheitslücken |
| `SUPPORT.md` | Hilfe und Kontakt |
| `ACCESSIBILITY.md` | Ziele zur Barrierefreiheit |

GitHub verwendet die unterstützten Dateien als Standard, soweit ein Repository keine eigene entsprechende Datei besitzt. Ein Repository kann diese Vorgaben überschreiben.

## Pflege

Änderungen möglichst per Pull Request abstimmen. Vor Veröffentlichung Kontaktdaten, Bildrechte und Richtlinien mit den zuständigen Verantwortlichen prüfen. Keine vertraulichen Schul- oder Personendaten in diesem öffentlichen Repository ablegen.

Die Lizenz wird für jedes Projekt separat festgelegt. Dieses Repository legt keine organisationsweite Softwarelizenz fest.
