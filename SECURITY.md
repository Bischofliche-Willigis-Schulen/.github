# Sicherheitsrichtlinie

## Sicherheitslücken melden

Bitte melde mögliche Sicherheitslücken **nicht über öffentliche Issues oder Pull Requests**. Nutze, sofern im jeweiligen Repository aktiviert, GitHubs Funktion „Report a vulnerability“ im Bereich Security. Alternativ wende dich vertraulich an [app@willigis-online.de](mailto:app@willigis-online.de).

Hilfreich sind folgende Angaben:

- Betroffenes Projekt und Version (oder Commit).
- Beschreibung der Schwachstelle und mögliche Auswirkungen.
- Schritte zur Reproduktion in einer zulässigen Testumgebung.
- Falls möglich ein Vorschlag zur Behebung.

Sende keine Passwörter, Tokens, personenbezogenen Daten oder vollständigen Datenbankabzüge. Falls solche Daten betroffen sind, beschreibe den Sachverhalt zunächst ohne deren Inhalt.

## Unterstützte Versionen

Verbindliche Angaben zu unterstützten Versionen stehen gegebenenfalls in der Sicherheitsrichtlinie des jeweiligen Projekts. Es gibt keine pauschale Supportzusage für alle Repositories.

## Verantwortungsvolle Offenlegung

Bitte ermögliche den Verantwortlichen eine Prüfung und stimme eine etwaige Veröffentlichung vorab ab. Diese Richtlinie erteilt keine Erlaubnis für Tests an produktiven Schulsystemen oder den Zugriff auf fremde Daten.
