# Mitwirken

Vielen Dank für dein Interesse an den digitalen Projekten der Bischöflichen Willigis-Schulen.

## So kannst du beitragen

1. Lies die README und die projektspezifischen Hinweise, einschließlich der Lizenz.
2. Prüfe offene Issues, bevor du einen neuen Vorschlag erstellst.
3. Stimme größere Änderungen zunächst mit den Projektverantwortlichen ab.
4. Arbeite in einem eigenen Branch oder, sofern zulässig, einem Fork.
5. Prüfe und teste deine Änderungen und aktualisiere die Dokumentation.
6. Erstelle einen Pull Request mit einer nachvollziehbaren Beschreibung.

## Qualitätsanforderungen

- Halte Änderungen möglichst klein und nachvollziehbar.
- Beachte die vorhandenen Formatierungs- und Testvorgaben.
- Verwende nur Inhalte, für die du die erforderlichen Rechte hast.
- Berücksichtige Datenschutz, Sicherheit und Barrierefreiheit.
- Verwende ausschließlich anonymisierte oder synthetische Testdaten.

Keine Namen, Noten, Stundenpläne mit Personenbezug, Zugangsdaten oder internen Schuldokumente veröffentlichen. Sicherheitsprobleme bitte vertraulich gemäß [SECURITY.md](SECURITY.md) melden.

Beiträge werden von den jeweiligen Projektverantwortlichen geprüft. Es besteht kein Anspruch auf Übernahme einer Änderung. Bei Fragen: [app@willigis-online.de](mailto:app@willigis-online.de).
